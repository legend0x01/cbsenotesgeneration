Welcome to NCERT Notes

Your notes are written by Google's Gemini AI. Gemini needs a free API key (a private password for the AI) from Google. Follow these steps once and you're ready to study.

  1. Sign in to save your notes Recommended

    Every chapter you generate is saved to your account, so you never have to generate it again, on any device.

  2. Open Google AI Studio

    It opens in a new tab. Sign in with any Google account. The first time, Google asks you to accept its terms: tick the boxes and press Continue.

    Open aistudio.google.com/apikey

  3. Click “Create API key”

    You'll find it on the API keys page. If Google asks you to choose a project, pick the one it suggests (or create a new one with any name) and confirm.

    Look for: Create API key

  4. Copy your key

    Your new key is a long code that starts with AIza. Click the copy icon next to it, or select the whole key and press Ctrl + C.

    AIzaSyB•••••••••••••••••••••••••••••••

  5. Paste it here and you're done

    We check the key with Google, then you can open any chapter.

Good to know

  • It's free. No credit card is needed, and the free tier is enough for daily study.
  • Free keys have limits on requests per minute and per day. If you see “Rate limit reached”, wait a minute and try again.
  • Under 18? Google's Gemini API terms say users must be 18 or older, so ask a parent or teacher to create the key for you.
  • Keep it private. Don't share your key. You can delete it any time on the same AI Studio page.
  • Where it's stored: your key stays in this browser only. When you sign in, your notes are saved to your account (your key is not).
